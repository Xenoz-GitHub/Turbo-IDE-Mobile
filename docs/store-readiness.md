**Credits: ENCRYPTED CREW**

## 1. Privacy Declaration
- **Network Permissions:** None requested. The application does not communicate with external servers, telemetry services, or third-party analytics.
- **Data Storage:** All files are stored strictly on-device in the app-private sandbox or the user-selected SAF folder.
- **Privacy Policy URL:** Hosted static on-device privacy document stating zero telemetry.

---

## 2. Accessibility
- VoiceOver (iOS) and TalkBack (Android) descriptions implemented on all buttons, dialogs, and navigation elements.
- Scalable dynamic text sizing on native chrome.
- High-contrast visual borders and color themes for accessibility.
